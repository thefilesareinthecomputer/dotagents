# _TEMPLATES/

**What it is:** the seed forms notes start from. Excluded from the knowledge graph (`.kgignore`) so blank scaffolding never shows up in search results.

**What lives here:** note templates - currently `note-template.md`.

**Feeds:** every folder, indirectly: new notes copy a template's shape.

## Standards

- Templates stay generic: placeholder values, no real content.
- A template change applies forward only; existing notes are never bulk-rewritten to match.
- Each template stays minimal: it gives the shape and does not explain it at length.
