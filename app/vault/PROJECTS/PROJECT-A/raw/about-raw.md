# About raw/

Drop zone for non-markdown source material: PDFs, spreadsheets, exports, images. The knowledge graph indexes only markdown, so nothing here pollutes search; the file tree still shows it, and `docs-*` notes distill it into linkable form.

Keep originals unmodified; anything superseded moves to `__archive/` like everything else.
