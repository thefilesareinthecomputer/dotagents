# PROJECT-A

The template project workspace: a committed, testable fixture showing the scaffolding every project workspace in this vault follows. Copy this folder to start a real project.

## File conventions

| Pattern | Holds | Examples here |
|---|---|---|
| `index.md` | The workspace home: goal, status, links to everything below | this file |
| `log.md` | Dated running log, append-only | [[PROJECTS/PROJECT-A/log|log]] |
| `docs-*` | Design and reference documents | [[docs-architecture]], [[docs-data-model]], [[docs-rollout-plan]] |
| `notes-*` | Working notes by thread | [[PROJECTS/PROJECT-A/notes-communications|notes-communications]], [[PROJECTS/PROJECT-A/notes-meetings|notes-meetings]], [[PROJECTS/PROJECT-A/notes-learnings|notes-learnings]] |
| `user-stories-*` | Requirements and story backlogs | [[PROJECTS/PROJECT-A/user-stories-backlog|user-stories-backlog]] |
| `raw/` | Non-markdown source material: PDFs, spreadsheets, exports | `raw/` |
| `code-*` | Notes on code artifacts, when a project has them | none in this sample - a docs-first project |

## Goal

Demonstrate the workspace format using itself as the subject. A real project states its objective here, lists its required knowledge (which the gap assessor scores against [[VAULT-KNOWLEDGE-LIFECYCLE|the knowledge base]]), and links its live threads.
