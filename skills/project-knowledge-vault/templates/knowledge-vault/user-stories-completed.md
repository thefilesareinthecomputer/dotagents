Finished work, moved here from [[user-stories]] rather than deleted, so the live board stays the live picture and the record of what was actually delivered survives the project.

An item arrives with its body and its sprint-board shape intact, so the same linter reads both files. Do not summarize it on the way in: the acceptance criteria and the evidence are what make it useful later, to whoever asks whether a thing was ever done and how it was proven. Each item closes with one line stating the date and how it ended: delivered, or descoped, superseded or duplicated, and by what. An item that vanishes reads as delivered.
