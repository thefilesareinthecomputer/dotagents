# UPDATES
[YYYY-MONTH](#YYYY-MONTH)

Authored status, newest first: the write-ups that go out to a stakeholder, and the per-topic summaries that pull a scattered subject into one place on one date. An update is written rather than transcribed, and it is addressed to someone.

An update is a snapshot on a date and goes stale by design. Never edit an old one to make it current; write a new one. A fact that outlives its update belongs in [[notes-learnings]].

> [!note] Entry format
> One H2 per update, `## YYYY-MM-DD-<TOPIC>`. Each month opens with a `# YYYY-MONTH` H1 and gets a jump link at the top of the file. Every subsection is optional.

```markdown
## YYYY-MM-DD-TOPIC

- **Audience** <ROLE or group> - **Period** YYYY-MM-DD to YYYY-MM-DD

<where things stand>

### DONE
- <what shipped, and what it means for whoever is reading>

### IN FLIGHT
- <what is underway, with the date it is expected>

### BLOCKED
- <what is stuck, who owns unblocking it, and since when>
```
