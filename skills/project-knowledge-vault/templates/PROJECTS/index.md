# <PROJECT> Knowledge Vault

The shared operational source of truth for the <PROJECT> project. One line on what this project delivers and for whom.

The contract every note here satisfies is in [AGENTS.md](AGENTS.md). Read it before writing.

## Reference

- [00-brd](00-brd.md) - The requirements: what this project is accountable for delivering, and the constraints it delivers under.

## Notes

- [notes-chat](notes-chat.md) - Message threads worth keeping, including email, one dated section per exchange.
- [notes-learnings](notes-learnings.md) - Durable facts written to outlive the threads that produced them.
- [notes-meetings](notes-meetings.md) - Standups, working sessions, refinements and planning, one dated section per meeting.
- [notes-pr-reviews](notes-pr-reviews.md) - Story and pull-request reviews, each dated section carrying the item under review and its comment thread.
- [notes-questions](notes-questions.md) - The open-question register, the only home for a question still awaiting an answer.
- [notes-updates](notes-updates.md) - Status write-ups and per-topic summaries.

## Work

- [user-stories](user-stories.md) - The live board.
- [user-stories-tasks](user-stories-tasks.md) - The run sheet for in-flight stories, and the scratchpad work is handed back and forth in.
- [user-stories-completed](user-stories-completed.md) - Cold storage for finished work.

## Change history

- [log](log.md) - What was added, removed, renamed or materially changed, and when.
