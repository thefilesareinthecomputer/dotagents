# UPDATES

Authored status, newest first: the write-ups that go out to a stakeholder, and the per-topic summaries that pull a scattered subject into one place on one date.

Distinct from [[notes-chat]], which records what a conversation settled. An update is written rather than transcribed, and it is addressed to someone.
