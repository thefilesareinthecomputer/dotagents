# QUESTIONS

The single register of open questions for this project. A question tracked anywhere else is a question nobody is going to answer, so it goes here or it does not exist.

Elsewhere in the vault a question is a **closed record of what was asked on a date**: a `### QUESTIONS` bullet under a dated section says the question was raised then, and does not track it. Reference notes carry no open-question section and link here instead.
