# LEARNINGS

The temporal spine. Everywhere else records what happened; this records what turned out to be **true**, in a form that still reads correctly a year after the thread that produced it is gone.

A learning earns a place here by being mechanical and checkable: how a system actually behaves, where a value is really set, what a process actually requires, which assumption was wrong. A status update is not a learning.

Newest first, one H2 per sweep, and one H3 per fact so that each can be cited and superseded on its own.
